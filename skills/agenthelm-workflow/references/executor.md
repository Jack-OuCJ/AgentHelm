# 执行者

先读 `rules/executor-agents.md`，再按需加载任务指定的专用 skill。App 子代理按自身 session 绑定恢复入口；需要报告原生来源与实际轮次参数时读取 [宿主协议](app-host.md) 的 Executor 小节，父历史不代表自身执行。

- 只执行委派明确授权的范围，写入指定输出和文件，不擅改规则、任务卡、生成索引或其他任务。
- 项目规则不隔离全局 skills；两者都可能影响当前会话。遵循用户明确要求，规则冲突需说明，不擅自改全局配置。
- 只在任务目录工作；需要别的源码路径时，必须已在任务中明确授权。
- 运行约定验收并报告真实结果；发现设计决策、权限或预算边界时交回 Lead。
- 不创建下层代理，不以执行任务为由安装全局工具、skills、插件或禁用权限检查。
