# 瑞士风格动画演示：翻页控制规格

适用于 `claudedocs/` 下所有瑞士风格动画 HTML（agenthelm-intro、metagpt-harness、helpflow-deep-dive、funcsea-architecture、atoms-architecture）。用户已确认，2026-10-21。

## 模式

- 两种模式：**手动（默认）** 与 **自动**。每次打开页面均为手动；URL 带 `?mode=auto` 时以自动模式启动（展台/循环播放用）。
- 切换方式：`A` 键，或右下角提示区的模式开关（按钮，可点击，带 `aria-pressed`）。切换不重置当前页。
- 提示文案随模式变化：
  - 手动：`点击 / → 下一页 · ← 上一页 · A 自动播放`
  - 自动：`空格 / 点击 暂停 · ← → 切换 · A 手动模式`（暂停时：`已暂停 · 空格 / 点击 继续`）

## 手动模式

| 操作 | 行为 |
|---|---|
| 点击舞台、`→`、`PageDown`、空格 | 下一页：播放该页入场动画，播完**停在最终画面**，不自动跳转 |
| 当前页动画未播完时再次触发"下一页" | 立即结束当前页动画并进入下一页（下一页正常播放动画）；连续快速点击即连续翻页 |
| `←`、`PageUp` | 上一页：直接显示该页**最终画面**，不重播入场动画 |
| 点击进度条分段 | 跳到该页并播放入场动画 |
| 最后一页再"下一页" | 不动作（不回到第一页） |
| 第一页再"上一页" | 不动作 |

- "动画播完"的时刻：页面 `data-end`（毫秒）存在时用它，否则用 `data-dur`。若 `data-dur` 含较长停留时间，应为该页补 `data-end`，使进度条在动画实际结束时填满。
- 手动模式下场景时钟 `t` 到达动画结束时刻后钳住不再增长；所有 cue 与 hook 呈现最终状态。光标闪烁等循环装饰可继续（用独立的墙钟，不依赖被钳住的 `t`），不得因此改变布局。
- 进度条：当前段表示本页动画进度（播完即满），之前的段为满，之后的段为空。不再表示倒计时。

## 自动模式

- 保持现有行为：每页播放 `data-dur` 后自动进入下一页，末页后循环回第一页。
- 空格或点击舞台：暂停/继续。`←` `→` 与进度条分段：切换页面并播放动画。

## 通用

- `prefers-reduced-motion: reduce`：两种模式下进入任何一页都直接显示最终画面；手动模式仍需操作才翻页。
- 点击控件（进度条、模式开关）不得冒泡触发舞台的翻页/暂停。
- 不引入外部依赖；保持单文件自包含。实现集中在现有场景时钟（`go()` / `tick()`）上：核心是让 `if (t >= s.dur) go(cur + 1)` 只在自动模式生效，并加入"跳到最终画面"的入口。

## 验收（Ego Lite，1280×720）

1. 打开后停留超过当前页 `data-dur` + 3 秒，页面不跳转。
2. 点击一次：进入下一页并播放动画，播完停住。
3. 动画播放中快速连点两次：前进两页，无残影、无叠层、cue 状态正确。
4. `←`：上一页直接是最终画面。
5. 按 `A` 切到自动：自动翻页且末页循环；空格可暂停；再按 `A` 回到手动。
6. `?mode=auto` 打开即为自动模式。
7. 控制台无报错；375 宽下提示与开关不遮挡内容、无溢出。
